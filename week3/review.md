1. `int a[5]` contains five elements, indexed `a[0]` through `a[4]`.
2. The loop skips index 0 and writes `a[5]` out of bounds. Use `for (i = 0; i < 5; i++) a[i] = 0;`.
3. For fixed outcomes, maintain one counter per sum and increment the corresponding counter when each roll occurs; a switch can select the counter. An array is shorter and more scalable.
4. A definition creates the object or supplies the function body; an external declaration describes an identifier so it can be used, without necessarily defining it (for example, `extern int count;`).
5. A function has a return type, name, parameters and body. A caller needs its name, return type and parameter types; a prototype specifies these.
