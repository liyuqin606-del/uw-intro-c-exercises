1. Integer division applies when both operands are integers and truncates toward zero. If either operand is floating point, usual arithmetic conversions produce floating-point division.
2. Zero represents false; any nonzero value is true. Relational and equality expressions yield `0` or `1`.
3. A semicolon terminates a declaration, terminates an expression statement, and separates the three clauses of a `for` loop.
4. `int i = 0; while (i < 10) { printf("i is %d\n", i); i++; }`
5. `3 < 4` has value `1`.
6. With ordinary ordered numeric values, `water` is printed when `32 <= T && T < 212`.
7. `yes`: the nonzero value 3 is true.
8. Three `a` lines, one `b`, then one `c`. Without braces, only the first print belongs to the loop.
